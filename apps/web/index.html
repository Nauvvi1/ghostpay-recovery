Why it matters

The failure modes
nobody accounts for

Standard HTTP clients assume success or failure. Real distributed systems have a third state — completed but lost — and paid APIs make it expensive.

Duplicate payments

An impatient client retries a timed-out request. Without an idempotency key stored on-chain, the payment runs twice. 0.10 USDC becomes 0.20 USDC for one API response.

Missing responses

The blockchain confirms payment. The server crashes after writing the result but before sending the HTTP response. The client has no result and no way to prove it paid.

Costly manual recovery

Without durable operation IDs and a verifiable on-chain receipt, recovery means reading blockchain logs, reconciling ledgers, and issuing refunds manually.

How it works

Four steps.
Exactly one payment.

GhostPay links an immutable operation ID to a USDC payment on Arc. Every retry uses the same ID — the contract ensures it can only settle once.

01

Approve

The payer calls approve(ghostpay, 100000) on the USDC ERC-20 contract — an exact, one-time allowance for this operation.

02

Pay once

GhostPay.pay(operationId, merchant, amount, requestHash) records the receipt and transfers USDC atomically. A replay with the same ID returns false — no second transfer.

03

Retry safely

The client retries with the same operation ID. The server checks SQLite for an existing settlement — no second approval, no second transfer, no second execution.

04

Recover response

The durable job result stored before the fault is returned unchanged. In Arc mode, paymentOf(payer, operationId) proves settlement directly from on-chain state.

For developers

Zero dependencies.
Real recovery.

The browser SDK uses the EIP-1193 wallet API directly — no bundlers, no frameworks, no third-party runtime dependencies.

sdk/ghostpay.js TypeScript 
// Create a new operation (unique ID per API call)
const ghostpay = new GhostPayClient();
const op = await ghostpay.startDemo();

// Inject fault — HTTP response aborted after payment committed
try {
  await ghostpay.attemptDemo(op.operationId, 'lost-response');
} catch { /* HTTP response aborted to simulate network loss */ }

// Retry with the SAME operationId — no second payment
const recovered = await ghostpay.attemptDemo(
  op.operationId,
  'lost-response'
);

console.log(recovered.state.result);
// { reportId: 'RPT-...', riskScore: 42, confidence: 0.97 }
// paymentCount = 1 even after 5 retries
